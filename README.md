# Habit & Streak Tracker

A web-based habit tracking application that helps users build consistency by tracking daily habits, calculating streaks, measuring completion rates, and visualizing progress through a calendar heatmap dashboard.

## Live Demo

https://is-project-2026.github.io/habit-streak-tracker-166289/

## Features

- Add habits with custom target frequency
- Track daily habit completion
- Current streak calculation
- Longest streak calculation
- Completion rate tracking
- Consistency score tracking
- Calendar heatmap dashboard
- LocalStorage persistence
- Responsive design
